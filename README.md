# [Harmonic Lab](https://luke-a-wendt.github.io/harmonic-lab)

**Music · Mathematics · Sound**

Harmonic Lab is an interactive, browser-based music and pitch exploration application.

## What's included

- `index.html` — the complete Harmonic Lab application.
- `README.md` — this overview.

## Using Harmonic Lab

Open `index.html` in a modern web browser. The application includes four main pages:

- **Explore:** Select scales, chords, and tonics; play notes on virtual instruments; compare pitch coordinates and relationships.
- **Tuner:** Choose an instrument and tuning peg, hear reference notes, and tune with microphone-assisted pitch detection.
- **Tab:** Browse tablature, play arrangements, and select a target key and scale directly on the page. The current Explore selection is offered as the initial target.
- **Math:** Explore the mathematics behind pitch and frequency.

The Explore and Tab spectrograms support microphone play-along. Their colors distinguish microphone measurements (white), melody or scale notes (cyan), and chords (magenta).

## Audio and microphone

Sound playback uses your browser's audio engine. Microphone access requires permission and may be restricted when opening a local file; if the browser blocks microphone access, open the app from a secure local or HTTPS origin. Headphones help reduce microphone pickup of synthesized reference tones.

The application does not require an account.
